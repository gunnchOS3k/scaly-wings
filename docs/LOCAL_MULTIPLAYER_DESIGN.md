# Local Multiplayer Design

## Same-device multiplayer

| Game | Mode |
|------|------|
| Larva Leaf Race | P1 vs P2 grid race |
| Pinball | Single player (future dual-flipper co-op) |
| Wing Run | Single player |

## Controller assignment

- Player 1: first gamepad or touch left / WASD
- Player 2: second gamepad or touch right / arrows
- Assign in **Cocoon Console Mode**

## Split touch

- Larva: left pad = P1, right pad = P2
- Pinball: left/right flipper zones

## Fairness & accessibility

- Equal-sized touch zones
- No pay-to-win; fictional scores only
- Clear on-screen player labels

## Supported games

Larva Leaf Race (full), Pinball/Wing Run (controller P1), Probability wing (single player).
